# DevInfra

여러 프로젝트에 걸친 **개발 인프라 · 공통 운영**을 담는 리포. 개별 앱 코드는 여기 두지 않는다.

현재 담고 있는 것:

| 경로 | 내용 |
|---|---|
| `TASKS.md` | 이 리포가 다루는 작업의 **상태 정본** (작업 원장) |
| `docs/research/` | 도구·기술 선택을 위한 조사 보고서 |
| `docs/design/` | 확정된 결정 기록과 착수 전 브리핑 |

## 왜 별도 리포인가

Gitea 같은 공통 도구 구축은 어느 앱 프로젝트에도 속하지 않는다. 처음엔 `OhMyEnglish/docs/`에 두었는데
용도가 다중 프로젝트로 확장되면서 집이 맞지 않게 됐다 — 앱 리포에 두면 그 앱을 안 볼 때 문서도 안 보이고,
프로젝트별 `TASKS.md`와 상태가 섞인다.

## 원장 규약

`TASKS.md`가 이 작업 상태의 정본이다. 프로젝트별 `TASKS.md`(`OhMyEnglish/TASKS.md` 등)와 **서로 참조하지 않는다.**
같은 내용을 두 곳에 쓰지 않고, 한쪽이 다른 쪽을 가리킨다.
